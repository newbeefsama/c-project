## ⭐ 全新的领域：文件

**你之前写的所有程序，数据都是"程序一结束就没了"。**

```c
int a[100];        /* 程序退出，这块内存回收，数据消失 */
```

**文件不一样：**

```
程序运行 → 写文件 → 程序退出 → 下次运行 → 读文件 → 数据还在
```

**这就是"持久化"。** 游戏存档、配置、日志、文档——全靠文件。

## 🔒 文件操作的三条铁律

### 铁律 1：`fopen` 可能失败

```c
FILE *fp = fopen("data.txt", "r");
```

**失败时返回 `NULL`**，原因包括：
- 文件不存在
- 没有读权限
- 路径写错了
- 文件被别的程序占用

```c
if (fp == NULL) {
    /* 必须处理！否则下一步 fgetc(fp) 直接崩 */
    return 0;
}
```

> **`fopen` 判空和 `malloc` 判空是同一类事——你已经在 `malloc` 上栽过 4 次了。**

### 铁律 2：打开的文件必须 `fclose`

```c
FILE *fp = fopen(...);
... 读写 ...
fclose(fp);        /* ← 不能忘 */
```

**忘了会怎样？**
- **文件句柄泄漏**——操作系统能同时打开的文件数是有限的（通常几千个）
- **数据可能没真正写入磁盘**——缓冲区里的内容可能丢失

> **这就像 `malloc` 之后忘了 `free`，但更严重——因为操作系统资源更稀缺。**

### 铁律 3：`fgetc` 返回 `int`，不是 `char`

```c
char c = fgetc(fp);          /* ❌ 错的！ */
int  c = fgetc(fp);          /* ✅ 正确 */

while (c != EOF) { ... }     /* EOF 是 -1 */
```

**为什么？** `fgetc` 成功时返回 `0~255` 的字符值，失败/结束时返回 **`EOF`（-1）**。

**`char` 装不下 256 个值 + 一个特殊值 -1：**

- 如果 `char` 是 **signed**（`-128~127`），字节值 `0xFF` 会被当成 `-1` → **跟 EOF 混淆** → 提前结束读取
- 如果 `char` 是 **unsigned**（`0~255`），`EOF`（-1）会被转成 **255** → **永远不等于 EOF** → 死循环

> **所以标准库特意让 `fgetc` 返回 `int`。这是 C 里非常经典的设计。**

## 📝 Part A：文件基础

### A1. `file_read_all` —— 读整个文件

**思路：用动态缓冲区，一个字符一个字符地读。**

```
① fopen "r"     → 判空
② malloc 64 字节的缓冲区
③ while fgetc != EOF:
      缓冲区满了 → realloc 翻倍
      把字符放进去
④ 末尾加 '\0'
⑤ fclose
⑥ 返回缓冲区（调用者负责 free）
```

**⚠️ 所有失败路径都要 `fclose` + `free` 已经申请的内存**（和 `da_create` 两次 malloc 的回滚是同一个道理）。

**⚠️ 判断"满了"要用 `size + 1 >= cap`**——因为最后要留一格放 `'\0'`。

### A2. `file_write_all` —— 写文件

```c
FILE *fp = fopen(path, "w");     /* "w" = 覆盖写，原内容清空 */
if (fp == NULL) return 0;
fputs(content, fp);
return (fclose(fp) == 0) ? 1 : 0;   /* fclose 也可能失败！ */
```

**模式说明：**

| 模式 | 含义 |
|---|---|
| `"r"` | 读（文件必须存在） |
| `"w"` | 写（**覆盖**，文件不存在就创建） |
| `"a"` | 追加（写到末尾，不覆盖） |
| `"r+"` | 读写（文件必须存在） |

### A3. `file_copy` —— 复制文件

**最简单的方法：读出来 + 写进去。**

```c
char *buf = file_read_all(src, NULL);
if (buf == NULL) return 0;
int ok = file_write_all(dst, buf);
free(buf);
return ok;
```

**（进阶：大文件不应该一次全读进内存——可以一块一块地读，每次 1024 字节。做完想想为什么。）**

## 📝 Part B：`file_stats` —— 统计

### 三个指标的精确定义

| 指标 | 定义 |
|---|---|
| **chars** | 字符总数（`'\n'` 也算 1 个） |
| **lines** | `'\n'` 的个数 + （文件非空且最后不是 `'\n'` 时加 1） |
| **words** | 连续的非空白字符段数 |

**空白字符 = `' '` `'\t'` `'\n'` `'\r'` `'\v'` `'\f'`**

### ⭐ 单词计数的核心：`in_word` 状态

**错误做法：遇到空白就 `words++`。**

```
"hello world"
       ↑ 只有 1 个空格，但单词数是 2 —— 这样数不对
```

**正确做法：数"从空白进入非空白"的次数。**

```c
int in_word = 0;

while ((c = fgetc(fp)) != EOF)
{
    if (是空白)
        in_word = 0;                    /* 离开单词 */
    else
    {
        if (!in_word) { words++; in_word = 1; }   /* 刚进入一个新单词 */
    }
}
```

**图示：**

```
文本:  " a  bb "
状态:   0 1  0 1  0
         ↑ ↑  ↑ ↑  ↑
         进入 离开 进入 离开
        words: 1      2
```

**这就是"状态机"的思路**——用一个变量记录"当前在不在单词里"。

### 行数的坑

```c
if (chars > 0 && last != '\n') lines++;
```

**因为 `"abc"` 没有换行符，但它是 1 行。**

| 内容 | `'\n'` 数 | 加 1？ | 行数 |
|---|---|---|---|
| `""` | 0 | 不加（空文件） | **0** |
| `"abc"` | 0 | 加 | **1** |
| `"abc\n"` | 1 | 不加（已结尾） | **1** |
| `"abc\ndef"` | 1 | 加 | **2** |
| `"abc\ndef\n"` | 2 | 不加 | **2** |

## 📝 Part C：单词计数（动态数组 + 排序）

### C1. `wl_create`
和 `da_create` **一模一样**：两次 `malloc`，都判空，初始容量 4。

**⚠️ 大小是 `4 * sizeof(WordCount)`，不是 `4 * sizeof(int)`。**

### C2. `wl_add` —— 添加/累加

```
① 遍历 items，用 strcmp 找
   找到  → items[i].count++;  return;
② 没找到 → 新增：
   a. 满了就扩容（翻倍）
   b. 把 word 复制进 items[size].word（注意别超过 WORD_MAX-1）
   c. items[size].count = 1;
   d. size++;
```

**这是"用数组实现一个简易的哈希表/字典"**——虽然查找是 O(n)，但逻辑简单清晰。

### C3. `wl_count_text` —— 切词

**思路和 `file_stats` 的单词计数一样，只是要多存一个"临时单词缓冲区"：**

```
遇到非空白 → 塞进 buf
遇到空白   → 如果 buf 非空：
                buf 结尾加 '\0'
                wl_add(wl, buf)
                清空 buf
```

**⚠️ 循环结束后 buf 里可能还有最后一个单词**（因为最后一个词后面可能没有空白）。

### C4. `wl_sort` —— 冒泡排序

```c
for (int i = 0; i < wl->size - 1; i++)
    for (int j = 0; j < wl->size - 1 - i; j++)
        if (需要交换) { 交换 items[j] 和 items[j+1] }
```

**⚠️ 交换的是整个 `WordCount` 结构体**（包含 `word` 数组和 `count`）：

```c
WordCount t = wl->items[j];
wl->items[j] = wl->items[j+1];
wl->items[j+1] = t;
```

**结构体赋值是"整体拷贝"——`word` 数组的内容也会一起复制。**

### C5. `wl_print_top` —— 打印前 N 名

```c
printf("%4d. %-12s %4d\n", i+1, wl->items[i].word, wl->items[i].count);
```

| 格式 | 含义 |
|---|---|
| `%4d` | 宽度 4，右对齐 |
| `%-12s` | 宽度 12，**左对齐**（`-` 表示左对齐） |

### C6. `wl_free`
和 `da_free` 一样：`free(items)` → `free(wl)`。

## 💡 常见坑

| 坑 | 后果 |
|---|---|
| **`fopen` 不判空** | 文件不存在时 `fgetc(NULL)` 崩溃 |
| **忘了 `fclose`** | 文件句柄泄漏、数据没写进磁盘 |
| **`char c = fgetc(fp)`** | 字节 `0xFF` 被误判成 EOF，或者死循环 |
| 单词计数用"遇空白就 ++" | 多个连续空格会多算 |
| 行数忘了"最后一行不加换行" | `"abc"` 被算成 0 行 |
| `wl_add` 复制单词时不限长度 | 缓冲区溢出 |
| `wl_count_text` 忘了最后一个词 | 少一个词 |
| 扩容时 `sizeof(int)` 写成 `sizeof(WordCount)` 的反面 | 内存不够，堆损坏 |
