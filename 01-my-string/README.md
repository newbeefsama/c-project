## 📝 七个函数逐个说明

### 1. `my_strlen` —— 算长度
```c
size_t my_strlen(const char *s);
```
数到 `'\0'` 为止（**不包含 `'\0'`**）。

**思路 A（下标）**：`while (s[i] != '\0') i++;`
**思路 B（指针）**：`const char *p = s; while (*p) p++; return p - s;`

> `size_t` 是"无符号整数"类型，专门表示长度。用 `%zu` 打印。

---

### 2. `my_strcpy` —— 复制
```c
char *my_strcpy(char *dest, const char *src);
```
把 `src` 的内容（**含 `'\0'`**）复制到 `dest`，**返回 `dest`**。

⚠️ 注意：
- `dest` 必须有足够空间（调用方保证）
- 要复制 `'\0'`，否则目标串没有结束符

---

### 3. `my_strcat` —— 拼接
```c
char *my_strcat(char *dest, const char *src);
```
把 `src` 接到 `dest` 的**末尾**，返回 `dest`。

**两步：**
1. 先找到 `dest` 的末尾（`'\0'` 的位置）
2. 从那里开始复制 `src`（含 `'\0'`）

⚠️ `dest` 必须有足够空间装下两个串。

---

### 4. `my_strcmp` —— 比较
```c
int my_strcmp(const char *s1, const char *s2);
```
逐字符比较（按 **ASCII 码大小**），返回：

| 情况 | 返回 |
|---|---|
| `s1 == s2` | **0** |
| `s1 < s2` | **负数** |
| `s1 > s2` | **正数** |

⚠️ **两个坑：**
- 不能用 `return s1[i] - s2[i];` 直接返回差值——**标准只要求返回正/负/零**，但差值可能溢出 `int`
- 遇到 `'\0'` 要停下

---

### 5. `my_strrev` —— 反转
```c
void my_strrev(char *s);
```
**原地**把字符串反转（`"hello"` → `"olleh"`）。

**思路：** 双指针，一个头一个尾，交换后向中间靠拢。

⚠️ 什么时候停？——**`left < right`**（不是 `<=`，也不是 `!=`）。

---

### 6. `my_strchr` —— 查找字符
```c
char *my_strchr(const char *s, int c);
```
在 `s` 里找**第一个**字符 `c`，返回**指向它的指针**；找不到返回 **`NULL`**。

⚠️ 三个坑：
1. 参数 `c` 是 `int` 不是 `char`（历史原因）
2. **要能查找 `'\0'`**：`my_strchr("abc", '\0')` 返回指向末尾 `'\0'` 的指针
3. 返回类型是 `char *`，但参数是 `const char *`——需要处理这个转换

---

### 7. `my_atoi` —— 字符串转整数（最难）
```c
int my_atoi(const char *s);
```
把字符串转成整数：

| 输入 | 输出 | 说明 |
|---|---|---|
| `"123"` | 123 | 普通 |
| `"-45"` | -45 | 负数 |
| `"+7"` | 7 | 正号 |
| `"  789"` | 789 | **跳过前导空格** |
| `"12ab"` | 12 | 遇到非数字就停 |
| `"abc"` | 0 | 没有数字 |
| `""` | 0 | 空串 |
| `"0"` | 0 | 零 |

**步骤建议：**
1. 跳过前导空白（空格、`\t`、`\n`）
2. 处理正负号
3. 循环：遇到数字就 `result = result * 10 + (c - '0')`，否则停
4. 返回结果（记得乘上符号）

## 💡 常见坑（你以前踩过的）

| 坑 | 提醒 |
|---|---|
| 数组越界 | 算长度时别忘了 `'\0'` 不计数 |
| 忘了复制 `'\0'` | `strcpy`/`strcat` 一定要复制结束符 |
| 循环条件用 `!=` | 用 `<`（反转的 `left < right`） |
| 指针类型不匹配 | `const char *` 和 `char *` 不能随便互转 |
| 编译警告不看 | **这次一定要看**——`-Wall -Wextra` 会告诉你很多 |
