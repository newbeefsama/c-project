# 项目 7：通讯录（从零设计）

> ⚠️ **这个项目没有骨架、没有提示、没有测试文件。**
> **所有代码你自己写。我只在你卡死的时候给方向。**

---

## 🎯 你要做一个什么程序

**一个命令行通讯录：**

```
==============================
      我的通讯录
==============================
1. 添加联系人
2. 显示全部
3. 查找联系人
4. 修改联系人
5. 删除联系人
6. 保存
0. 退出
==============================
请选择：
```

**核心要求：数据要保存到文件——关掉程序再打开，联系人还在。**

---

## 📋 功能要求

| # | 功能 | 说明 |
|---|---|---|
| 1 | **添加** | 输入姓名、电话、地址，存进去 |
| 2 | **显示全部** | 列出所有联系人，格式整齐 |
| 3 | **查找** | 输入姓名，显示匹配的联系人 |
| 4 | **修改** | 找到某个人，改他的电话/地址 |
| 5 | **删除** | 找到某个人，删掉 |
| 6 | **保存 / 加载** | 存到文件；启动时自动读取 |
| 0 | **退出** | 退出前自动保存 |

## 🤔 几个设计决策（你自己定，没有标准答案）

### 决策 1：用什么数据结构？

| 选项 | 优点 | 缺点 |
|---|---|---|
| **动态数组** | 显示、查找快；代码你熟 | 删除要移动元素 |
| **链表** | 删除快 | 查找慢；显示要遍历 |

**建议：动态数组**（因为"显示全部"和"查找"是主要操作）。

### 决策 2：文件格式？

**方案 A：文本格式（推荐）**
```
张三|13800138000|北京市朝阳区
李四|13900139000|上海市浦东新区
```
**优点：** 用记事本就能看、能改、好调试。

**方案 B：二进制格式**
直接 `fwrite` 结构体数组。
**缺点：** 记事本打开是乱码；结构体一变就对不上。

**建议：方案 A。**

**⚠️ 注意：姓名/地址里如果出现 `|`，格式会乱。**（想想要不要处理）

### 决策 3：长度上限？

```c
#define NAME_MAX 32
#define PHONE_MAX 20
#define ADDR_MAX  64
```
**或者用指针动态分配字符串**（更难，但更灵活）。

**建议：先用固定数组，简单可靠。**

## 🆘 卡住了怎么办

**按这个顺序：**

1. **先画图** —— 通讯录的内存结构长什么样？文件长什么样？
2. **用 printf 调试** —— 每个函数进出都打印一下状态
3. **最小复现** —— 单独写个 10 行的小程序，只测出问题的那一小块
4. **再来问我** —— 带上：**代码 + 报错/现象 + 你试过什么**

**我不会直接给你代码，但会告诉你想错在哪。**
